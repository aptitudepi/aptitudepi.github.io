Voice Authentication System - 2024 TAMUHack

Developed an innovative voice authentication system to combat voice phishing scams. The project integrates hardware (Raspberry Pi and a USB key) with software components (NVIDIA NeMo ASR, Flask) to provide secure audio verification. Users are authenticated through voice recognition and AI-generation detection, ensuring a robust security solution.

Key features include: - Multi-factor authentication combining credentials and voice recognition - AI-generated voice detection - Hardware key integration for enhanced security - Web interface for user interaction

This project showcases skills in hardware integration, machine learning application, and web development, as well as the ability to overcome challenges such as cross-platform compatibility and hardware limitations.
